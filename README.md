# VidaPlena - Landing Page

Sitio web estático desarrollado como proyecto práctico de desarrollo web Front-End.

## Descripción

Landing Page para VidaPlena SpA, empresa de servicios de bienestar y salud integral.
La página presenta los servicios, testimonios de clientes y un formulario de contacto.

## Tecnologías utilizadas

- HTML5
- CSS3 (Flexbox, variables CSS, media queries)
- Git y GitHub

## Estructura del proyecto

## Cómo ver el proyecto

1. Clona el repositorio
2. Abre el archivo index.html en tu navegador
3. O usa Live Server en VS Code

## Uso de IA

Durante el desarrollo utilicé Claude como herramienta de apoyo de las siguientes formas:

- **Guía de aprendizaje:** me explicó cada etiqueta HTML y propiedad CSS paso a paso
- **Corrección de errores:** me ayudó a identificar errores de sintaxis en el código
- **Prompts utilizados:**
    - "¿Qué significa esta etiqueta HTML?"
    - "¿Por qué usar variables CSS?"
    - "¿Cómo funciona Flexbox?"
- **Adaptaciones realizadas:** modifiqué el contenido, colores y estructura según
  mi criterio propio, entendiendo cada línea de código escrita
